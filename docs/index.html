Skill yang ditunjukkan

  • Exploratory Data Analysis — pembersihan, visualisasi, dan pemahaman pola data tabular
  • Pemodelan prediktif — Artificial Neural Network (TensorFlow/Keras) dan machine learning klasik (scikit-learn)
  • Evaluasi model — metrik klasifikasi/regresi, validasi, dan tuning
  • Deployment — model dikemas sebagai aplikasi web interaktif (Streamlit)
  • Manajemen artefak — model terlatih (.keras, .joblib) dan dataset dikelola rapi per proyek

Menjalankan aplikasi

git clone https://github.com/farrelfz/data-science-farrelfz.git
cd data-science-farrelfz/attrition  # atau insurance / subscription
pip install -r requirements.txt
streamlit run app.py
